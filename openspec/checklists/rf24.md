## 5. WiFi jam expectation

The ESP32-Bit-Pirate implementation can also spam 802.11 beacons because the ESP32 has a WiFi
radio. **RP2350 does not.** The RB-Pirate `jam -g wifi` command is therefore an nRF24 continuous-
carrier sweep over WiFi-overlapping channels, not an 802.11 frame injector.

Acceptance criteria for this fork:

- [ ] The command is labeled as a **WiFi-band carrier sweep**, not full WiFi jamming.
- [ ] A second nRF24/SDR confirms carrier energy on the swept channels.
- [ ] The help/README do not claim 802.11 beacon injection or guaranteed WiFi denial.

If actual 802.11 jamming is required, it needs a separate WiFi-capable radio and a new hardware
change. It cannot be implemented on the RP2350 alone.
